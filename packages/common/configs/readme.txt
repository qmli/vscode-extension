Config（配置）

定义：Config 通常指的是应用程序、框架或系统层面的配置文件，它更倾向于开发者层面的设定，定义了应用如何运行、与其他系统如何交互等。Config 通常较为“全局”。

特点：

全局性：配置文件通常定义了系统级别的参数，不只是针对单一用户的设置。

持久性：配置文件通常会长期存在，不会频繁更改，除非进行系统更新或升级。

配置可以包括数据库连接信息、日志设置、API 密钥等。

示例：

一个 Web 服务的配置文件（例如 config.json 或 config.yaml），其中包含数据库连接字符串、API 接口的根 URL 等。

在 Django 或 Flask 等框架中，settings.py 或 config.py 文件用于配置数据库、缓存、邮件服务等信息。
